Text data only. In this approach, you opt to receive all key events without the key binding, and

that generated them, and modifier flags. This data is then sent to the inputText(_:key:
modifiers:client:) method, which you need to implement.

IMKServerInput
IMKServerInput is an informal protocol that defines methods for receiving tex
events. This is intentionally not a formal protocol because there are three ways to
receive events. An input method chooses one of the following approaches and
