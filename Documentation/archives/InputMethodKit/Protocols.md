Key binding. In this approach the system tries to map each key-down event to an action metho
that the input method has implemented. If successful (action method found), the system calls
didCommandBySelector:client:. If unsuccessful (action method not found), the system
calls inputText:client:. For this approach you need to implement inputText(_:
client:) and didCommand(by:client:).
Text data only. In this approach, you opt to receive all key events without the key binding, and
then unpack the relevant text data. Key events are broken down into the Unicodes, the key cod
that generated them, and modifier flags. This data is then sent to the inputText(_:key:
modifiers:client:) method, which you need to implement.
Handle all events. In this approach, you receive events directly from the Text Services Manager
as NSEvent objects. You must implement handle(_:client:) method.
