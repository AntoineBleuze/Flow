## Page 1

To display an application, category, or web domain, choose an ApplicationToken, Activity
CategoryToken, or WebDomainToken that represents an item selected by the user. For
example, you can access these tokens from the FamilyActivitySelection bound to a
FamilyActivityPicker view.
Use one of these tokens to create a Label instance by passing the token to its initializer. Display
the activity item like any SwiftUI view.
