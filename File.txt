Rôle de l'IA

Tu es un expert en UI/UX Design spécialisé dans le framework React, Tailwind CSS et les principes de l'Apple Human Interface Guidelines (HIG).

Tâche

Créer un composant "Tab Bar" (barre de navigation inférieure) pour une application iOS/Web mobile.
Le style visuel doit être "Liquid Glass" (Glassmorphism) et inclure une fonctionnalité de recherche intégrée spécifique.

Spécifications Visuelles : Style "Liquid Glass"

Le composant doit simuler une surface de verre liquide et givré. Utilise les propriétés CSS suivantes via Tailwind :

Transparence et Flou : Un fond blanc/gris très translucide (bg-white/10 ou bg-black/20) combiné à un fort flou d'arrière-plan (backdrop-blur-xl ou backdrop-blur-2xl).

Bordures Lumineuses : Une bordure supérieure fine et subtile (border-t) avec une couleur blanche semi-transparente (border-white/20) pour simuler le reflet de la lumière sur la tranche du verre.

Ombres et Profondeur : Une ombre portée douce (shadow-lg) et potentiellement une légère lueur interne.

Dégradé de fond (Contexte) : Pour que l'effet de verre soit visible, place la Tab Bar sur un fond d'écran coloré ou dégradé (vif et saturé).

Spécifications Fonctionnelles : Recherche dans la Tab Bar

Conformément aux directives HIG ("Search in a tab bar"), la recherche doit se comporter ainsi :

Positionnement :

La barre contient des icônes de navigation (ex: Home, Browse, Library).

Le champ de recherche est positionné sur le côté "trailing" (à droite) ou occupe un onglet distinct visuellement.

États du champ de recherche (Focus vs Unfocused) :

État Inactif (Unfocused) : Le champ doit être visible mais discret, invitant à la découverte. Il peut ressembler à une pilule de verre translucide.

État Actif (Focused) : Au clic, le champ doit s'étendre ou s'illuminer, prêt à la saisie.

Contenu du champ :

Placeholder : Utilise un texte descriptif comme suggéré dans la doc (ex: "Shows, Movies, and More") et non juste "Search".

Icône : Inclure une icône de loupe (Search icon) et un bouton "Clear" (x) qui apparaît quand du texte est saisi.

Ergonomie :

Utilise des transitions fluides (transition-all duration-300) lors du passage de l'état inactif à actif.

Assure-toi que les cibles tactiles sont assez grandes pour le mobile.

Stack Technique

React (Functional Component).

Tailwind CSS (pour le styling et les effets de verre).

Lucide-React (pour les icônes).

Résultat Attendu

Fournis le code complet du composant React dans un seul fichier, incluant un conteneur de démonstration avec un fond coloré pour mettre en valeur l'effet "Liquid Glass".
